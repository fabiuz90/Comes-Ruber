# 🍷 Comes Ruber — Private Label Wine Project

> *"Comes Ruber"* (Latino per *Conte Rosso*) è un progetto di brand, landing page e identity digitale dedicato a una selezione esclusiva di vino rosso d'alto profilo.

---

## 📌 Visione del Progetto

**Comes Ruber** (commercializzato come **Graf Rosso**) nasce con l'obiettivo di coniugare l'eleganza della tradizione vinicola italiana con un'identità visiva d'impatto e moderna. Il progetto abbraccia la progettazione dell'etichetta, la conformità alle normative europee (e-label / QR code) e la presentazione digitale della cantina.

---

## 🎨 Brand & Identity

* **Nome Brand:** Graf Rosso / Comes Ruber
* **Posizionamento:** Vino Rosso di fascia alta / Selezione Privata
* **Stile Visivo:** Dark mode, oro metallico su carta goffrata scura, minimalismo nobiliare.
* **Palette Colori:**
  * `#000000` — Nero Antracite / Sfondo
  * `#D4AF37` — Oro Warm Metallic (Dettagli ed Etichetta)
  * `#722F37` — Rosso Rubino Profondo (Ceralacca / Contorni)

---

## 📋 Specifiche Tecniche dell'Etichetta (Conformità UE)

Il progetto rispetta la normativa vigente sull'etichettatura dei vini nell'Unione Europea:

- [x] **Denominazione di Categoria:** Vino Rosso d'Italia / IGT
- [x] **Tracciabilità:** Imbottigliamento via codice ICQRF
- [x] **Allergeni:** Indicazione *Contiene Solfiti*
- [x] **E-Label:** Integrazione QR Code per valori nutrizionali, ingredienti e smaltimento imballaggi (GL 70 / FOR 50)
