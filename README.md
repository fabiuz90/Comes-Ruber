# Comes-Ruber
Comes Ruber (Graf Rosso) è un progetto di brand identity, e-label e digital showcase per un vino rosso italiano di fascia alta. Unisce l'eleganza nobiliare latina a un design minimale scuro e oro, rispettando le normative UE su tracciabilità, QR code nutrizionale e conformità dell'etichetta per la distribuzione Private Label.
